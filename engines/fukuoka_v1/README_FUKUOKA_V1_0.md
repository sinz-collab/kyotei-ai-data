固定事項:
- 実進入で全再計算
- 展示ST単独の強補正禁止
- 当地成績 + 当地STが良い場合の展示ST減点免除
- 2コース差し頭floorは条件成立時のみ。強制1位化禁止
- 1着 / 2着 / 3着を独立評価
- 3着は低い頭確率だけで削らない
- 3頭→4/1/5、4頭→5/1/6
- 弱い4連動: 5×1.10, 6×1.08, 1×1.05。2/3は下げない
- 4連動の保護買い目は最大1点
- 買い目は `P1 × P2|P1 × P3|P1,P2`
- Main6 / Zure2 / Ana2
- odds / result は予想に使用しない
