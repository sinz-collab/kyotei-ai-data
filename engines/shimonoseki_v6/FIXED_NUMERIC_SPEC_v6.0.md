# 下関AI v6.0 固定仕様（本番候補）

## 処理順
前データ → 進入確定 → **全DBをactual courseへ再マッピング** → motor_recent → 節間 → 展示T+SUM → actual course順スリット → 逃げ弱点×攻め手×スリット×SUM → 複合攻め残差 → 1/2/3着別再正規化 → SAB → 10点。

## 進入変更
- 枠番の微調整ではなく、player_course / player_type_by_lane / ST-course / course prior を actual course で引き直す。
- スリット12分類も actual course 順。
- 進入変更時の全体pattern強度は0.70倍。ただし個別ST差は別残差で保持する。

## motor_recent（日程motor係数前）
- up: +1.5/+2.0/+2.3pt
- down: -1.3/-1.6/-1.8pt
- top2>=50: 1着+0.5 / 2着+0.8
- top3>=70: 2着+0.5 / 3着+1.0
- top2>=60かつup: 1着+0.7
- 日程motor係数: 初日1.00 / 2日目0.85 / 3日目0.70 / 準優0.55 / 最終0.45

## 節間
着順点 1:+1 / 2:+.6 / 3:+.3 / 4:-.2 / 5:-.6 / 6:-1。
節間ST点=clip((通常avgST-節間平均ST)/.10,-1,+1)。合成=0.8着順+0.2ST。
位置上限 3.5/4.5/5.0pt × 日程係数。

## 展示+SUM
同一群。2日目係数0.85。群上限±5pt。

## 逃げ崩れ
**逃げ率単独で大幅減点しない。** actual 1-course艇について、
逃げ弱点 × 相手の攻め手 × スリット一致 × SUM支持 の積でのみ残差移送。
actual 1-courseのkimariteが欠損時は、その選手のactual 1-course実績をproxyにし、欠損を0%扱いしない。

## 個別スリット残差
group patternで個別の明確な前出しを潰さない。
- 内隣より+.03: +1.2/+0.7/+0.4
- +.05: +2.2/+1.2/+0.6
- +.08以上: +3.2/+1.8/+0.8
- actual 2-courseが+.08以上かつ攻め手あり: +6.0/+2.6/+0.8（例外複合上限内）
3-6courseは攻め手0ならST差単独残差を付けない。

## 複合攻め残差
3〜5course中心。motor up / 節間上位 / 内隣よりST+.03 / SUM平均-0.10以内 / 攻め手あり。
- 3条件: +0.8/+0.5/0
- 4条件: +1.5/+0.8/+0.3
- 5条件: +2.5/+1.0/+0.5
既に各単独層で評価済みなので残差のみ。

## 禁止
結果・オッズを確率入力に使わない。粗い潮とprecise tideを二重掛けしない。
