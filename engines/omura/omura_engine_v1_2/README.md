# 大村競艇AI 自動予想エンジン v1

## 目的

大村AI v6.1の運用順序を、再現可能な自動予想処理として実装するための初期エンジンです。

- 1号艇を大村場平均だけで過剰評価しない
- 当地成績、選手の格、選手×コース、決まり手を先に確認する
- モーター直近10走と決まり手は既存サイトJSONを正式入力にする
- 潮、風、波、時間帯は確率補正として反映する
- 展示・オリ展示・スリットは後半補正
- 進入変更時は実進入ベースで全再計算
- SABと買い目数を分離
- 買い目は本線6・ズレ2・荒れ2の計10点、重複なし
- オッズは確率、SAB、買い目選定に使用しない

## 現在の位置付け

本パッケージは「実行可能な統合エンジン骨格＋初期較正」です。
既存サイトの実データJSONを `input_schema.json` に合わせて接続し、最初の実レース検証後に補正係数を更新します。

シナリオLightGBM本体と280特徴量生成コードがローカル環境に存在する場合は、
`scenario_model_path` と `scenario_feature_builder` を接続してください。
モデル未接続時は、事前確率、決まり手、水面、スリットの整合からシナリオ確率を生成します。

## 重要：1号艇過剰評価防止

1号艇の場平均は最終確率ではなく事前アンカーです。

次の場合、1号艇の1着率を維持しません。

- 当地勝率が全国勝率より低い
- B1/B2で1コース実績の信頼度が低い
- 1コース逃げ率が低い、差され率が高い
- 2差し、3まくり、4カドの攻めシナリオが強い
- 前半戦・潮止まり・風波条件がイン信頼と矛盾
- 進入不確定
- 選手×1コースDBが場平均を下回る

1号艇への無条件加点は禁止しています。

## 実行

```bash
python scripts/run_prediction.py \
  --input samples/sample_input.json \
  --output samples/sample_output.json
```

## テスト

```bash
python -m unittest discover -s tests -v
```

## 主要出力

- 各艇の1着率、2着率、3着率、3着内率
- 大村専用展開シナリオ
- SAB
- 本線6点
- ズレ対応2点
- 荒れ対応2点
- 入力欠損とフォールバック記録
