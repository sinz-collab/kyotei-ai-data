# 大村自動予想エンジン 正式採用版

- 正式バージョン: `omura_engine_v1_9_production`
- 採用日: 2026-08-07
- ベース: v1.9 対抗頭買い目保証版

## 採用ロジック

1. サイトのタイドグラフから潮位・上げ下げ・満干潮距離を入力
2. 潮・風・波で高まった展開を攻め艇の着順確率へ連動
3. 初日はモーターと展示・オリ展示の一致を強化
4. 展示単独は主に2・3着補正
5. 高チルト外艇は3着限定補正
6. 1着率2位が15%以上なら対抗頭を最低1点、18%以上なら最低2点
7. オッズは表示のみで、確率・買い目・配分には不使用
8. 展示ST単独で確率を直接変更しない

## 配置

既存の大村エンジン配置先を本パッケージへ差し替え、マスターDB群は従来どおり外部の master-dir から参照してください。
