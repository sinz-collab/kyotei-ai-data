# 実装メモ

## 1号艇過剰評価対策

初期コース事前値の1コース1着率は56%を上限アンカーとし、既存大村集計の約68%をそのまま投入していません。

1号艇が56%を超えるには、以下のうち複数が必要です。

- A1/A2
- 当地勝率が全国勝率以上
- 信頼度の高い選手×1コース成績
- 逃げ率良好
- 相手の攻めリスクが低い
- 節間気配が良い

支持が3項目未満の場合は48%を上限とします。
B1/B2かつ当地成績が弱い場合は42%を上限とします。

これは最終固定値ではありません。最初の実レース検証後に、
1号艇の過小評価・過大評価、logloss、Brier、較正曲線を見て更新します。
