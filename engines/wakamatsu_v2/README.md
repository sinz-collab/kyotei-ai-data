# 若松自動予想エンジン v1.1

## 位置づけ
提供された若松DB、リーク除去済みOOF、潮・気象・選手×コースDB、運用ルールから構築した実用版です。

元の学習済みモデル本体と特徴量生成コードがないため、元OOFモデルの完全再現ではありません。
OOFは確率分布・検証・SAB校正に使用し、新規レースは実測DBと若松運用ルールで推論します。

## 反映順
1. コース基礎率
2. 選手×実コース
3. 実戦ST傾向
4. 潮×時間帯×水面タイプ
5. モーター
6. 節間
7. 展示・オリ展示の微補正
8. 展開シナリオと連動
9. 各着順100%へ再正規化
10. SAB
11. 固定10点

## SABと買い目
SABは予想精度・再現性の判定で、買い目数とは分離しています。

- 本線6点
- ズレ対応2点
- 荒れ対応2点
- 合計10点、重複なし
- オッズは予想に不使用

## 実行
```bash
python engine/wakamatsu_engine.py   --db data/wakamatsu_master_v1.sqlite   --input examples/sample_input_pre.json   --output examples/output.json
```

## テスト
```bash
python scripts/run_tests.py
```

## 入力
艇ごとの必須項目:
- lane
- entry_course
- player_id

任意の相対スコア（-1.0～1.0）:
- motor_score
- meeting_score
- exhibition_score
- original_exhibition_score

直前情報がない場合は省略できます。

## 出力
- 全艇1着率・2着率・3着率・3着内率
- 潮・風・水面条件
- 展開シナリオ
- SAB
- 本線6・ズレ2・荒れ2
- 自動検証結果

## 制約
- 元学習済みモデルの完全再現ではない
- モーター・節間・展示スコアは上流側で入力する
- SAB境界は今後の予想履歴で再校正する


## v1.1改善
- 初日はモーター通算値を自動スコア化し比重を上げる
- 干潮までの残り時間と下げ潮を確率補正
- 風速4m以上・波高4cm以上を展開分岐へ反映
- 実進入から攻め役を再設定
- 大幅進入変更を移動艇数・移動距離でSABへ反映
- 攻め艇頭＋外連動＋イン残りを荒れ対応で優先確認

## v1.2改善
- 攻め役を艇番ではなく実進入コースで判定
- 実進入の直外艇連動を生成
- 攻め艇頭＋直外艇＋イン残りを荒れ対応で優先
- 複数信号一致時のみ内側進入艇を追加補正

## v1.3改善
- 当地勝率・当地2連率・当地3連率を独立補正
- 全国成績との差も加点・減点
- 当地平均STを展示STより優先して補正
- 当地0.00は不利評価ではなくサンプルなし
- 初日は節間材料がないため当地適性を通常より重くする

## v1.4改善
- 艇番順ではなく実進入順でスリットの左右関係を判定
- 展示スリット遅れと当地STの遅さが一致した場合のみ左艇を減点
- 右横艇の展示スリットと当地STがともに良い場合のみ攻め加点
- 攻め艇の直外艇へ2着・3着連動補正
- 展示ST単独では大幅補正しない
- 補正内容を `slit_adjacency_adjustments` に記録

## v1.5改善
- スリット減点は左艇の当地STが0.18以上の場合だけ発動
- 相対的に右艇が速いだけでは左艇を減点しない
- 最上位の頭×2着候補について3着率10%以上を全確認
- 3着率上位3艇まで本線6点内に優先保持

## v1.6改善
- 最上位の頭×2着組は3着率10%以上を最大4艇まで本線内で被覆
- 3着候補を3艇に限定して4番手を落とす問題を修正

## v1.7改善
- オリジナル展示を6艇平均との差で評価
- 4コース艇が2着・攻め候補のとき5・6コース艇を再比較
- 格30%、モーター25%、通常展示15%、オリ展示15%、当地10%、位置5%
- 比較差が明確な場合のみ優位艇の2着・3着率を加点
- 劣位艇は大幅消しにせず3着率を小幅減点

## v1.8改善
- 4コース艇が2着候補になった組み合わせで5・6比較結果を買い目倍率へ反映
- 優位艇だけを全体的に過剰加点せず、`頭-4-優位艇`の展開内で優先
- 4攻め連動時の5・6順位と通常の3着率順位を分離

## v1.9改善
- 1コース逃げ率63%未満を中立以下として評価
- 逃げ率低下だけでは発動せず、2～4コースに複合攻め候補がいる場合のみ1頭を減点
- 攻め艇が複数なら全艇へ攻めスコア比率で1着率を配分
- 攻め艇頭では「攻め艇-直外艇-1号艇」を優先
- 低逃げ率と攻め候補が共存する場合はSABを減点

### 節間成績入力
`meeting_runs` を時系列で渡す。旧 `season_runs` も後方互換で読取可能。

各走で推奨する項目:
- `day_no`
- `race_no`
- `finish`
- `actual_course` または `entry_course`
- `start_time`
- `exhibition_score`
- `original_exhibition_score`

着順は実進入コースの期待値で補正し、直近走を重くする。
出力:
- `level_score`
- `recent_score`
- `trend_score`
- `stability_score`
- `trend_label` (`rising` / `flat` / `falling`)
