# 唐津シナリオエンジン v1.1.1

v1.1の最終確率バランスを維持しながら、元データを書き換えずに補正経路を調整した本番候補版です。

## 主な修正
- 1コース初期優位を緩和し、2〜6コースへ基礎確率を再配分
- 初日〜2日目のモーター寄与を30%から24%へ抑制
- 節間成績を2日目10%、中盤23%、終盤35%で段階反映
- 展示タイムの1着寄与を縮小し、外艇の好展示は2・3着へ優先配分
- 展示STは展開形状の補助に限定し、単独大幅加点を禁止
- 1着、2着、3着で別々の強度を生成
- 全艇比較の展示順位計算を修正
- S判定が10点運用でも発生可能になるよう条件矛盾を修正
- オッズは予想計算に不使用

## データ方針
モーター率、ボート率、節間着順などの元データは変更しません。変更対象は各着順への寄与率と補正幅のみです。
