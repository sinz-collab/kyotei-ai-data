# 唐津シナリオエンジン v1.2

唐津AIで検証した修正版を正式採用したエンジンです。

## v1.2の必須処理

- 節間成績を直近順で加重し、着順・コース・外枠好走を数値化
- 実進入変更時は全艇の基礎強度から全面再計算
- 頭候補ごとに2着・3着確率を再構成
- 三連単120通りを全採点
- 直前補正後に買い目10点を再生成
- SABを確率集中度・シナリオ整合性・買い目カバー率で再判定
- 3R終了後から同日水面傾向を小幅補正
- オッズは予想確率・買い目選定・金額配分に不使用

## 入力上の変更

`RacerInput`へ以下を追加できます。

```python
season_runs=[
    SeasonRun(finish=1, course=3, st=0.12),
    SeasonRun(finish=2, course=5, st=0.16),
]
```

`season_score`を直接指定した場合はその値を使用し、未指定の場合は`season_runs`から自動算出します。

実進入は`actual_course`へ必ず反映してください。  
例として6号艇が2コースへ前付けした場合、6号艇の`actual_course=2`とし、押し出された各艇も実際のコースへ更新します。

## 出力

- `marginal_first`
- `marginal_second`
- `marginal_third`
- `trifecta_probabilities`：120通り
- `tickets`：10点
- `sab`：S/A/B
- `diagnostics`

## SAB

Sは単なる1号艇高確率ではありません。以下が同時に必要です。

- 頭候補の明確な差
- 上位シナリオへの集中
- 上位10通りへの確率集中
- 10点買い目による十分なカバー
- 進入・風波・水面との矛盾がないこと

進入変更時は原則A以下とし、複数頭候補や風波4以上が重なる場合はBに落とします。

## 回帰検証対象

2026年8月1日の唐津2R・3R・4R・5R・7Rを固定検証対象とします。  
結果そのものを補正値へ使用せず、事前・節間・直前・実進入から順位が再現できるかを確認します。
